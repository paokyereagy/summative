# BSE Specialisation Advisor

An interactive web application that helps BSE students discover their ideal specialisation through a comprehensive quiz and skills assessment.

# Live Demo

[View Live Application](https://paokyereagy.github.io/summative.git/)

# Overview

This application guides incoming students through:
1. Student Registration - Collects student details with real-time validation
2. Interactive Quiz - 10 questions covering 4 specialisation areas
3. Results Analysis - Visual radar chart and detailed recommendations
4. Contact & Feedback- Submit inquiries and feedback

# Technologies Used

- HTML5- Semantic markup
- CSS3 - Responsive design, flexbox/grid, animations
- JavaScript (ES6+) - Vanilla JS, Canvas 2D API
- GitHub Pages - Hosting


# Features

# Form Validation
- Real-time inline validation with visual feedback
- Custom regex patterns for:
  - Student IDs: `BSE-YYYY-XXX`
  - BSE emails: `@alustudent.com`
  - Mauritian phone numbers
  - Name validation

# Interactive Media
- Image hotspots for visual interaction
- Custom audio player controls

# Timer & Scoring
- 10-minute countdown timer
- Auto-submit on timeout
- Multi-category scoring
- Speed bonus & streak multipliers

# Canvas Visualization
- Radar/Spider chart
- Custom Canvas 2D rendering
- Celebration particles for high scores
